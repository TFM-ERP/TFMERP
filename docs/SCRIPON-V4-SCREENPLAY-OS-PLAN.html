3 · The intelligence spine new · foundational

Canon Memory

An append-only canon ledger per script. Approved revisions write canon; every tool (rewrites, summaries, bibles, pitch, sequels, adaptations, translations) reads canon, not raw text — so continuity holds across the lifecycle.
CanonFact { id, scriptId, kind, subject, statement, sourceSceneId, supersedesId?, status, createdByRevisionId?, createdAt }

Scene dependency graph

Powers related-scene detection & the Conflict Detector. Built per revision, cached, recomputed on approved change.
SceneRelation { fromSceneId, toSceneId, type(REFERENCE|SETUP_PAYOFF|RELATIONSHIP| LOCATION|LORE|CALLBACK|CAUSE_EFFECT), strength, note }

Integrity Protection

A pre-apply check both scene engines run. Reads canon + the graph; validates arcs · timeline · location · cause/effect · dialogue · tone/genre · setup-payoff. Returns { ok, warnings[], suggestedFixes[] } — never blocks, always explains.

4 · New engine specs

Tool #1 — Scene Revision Engine · targeted, continuity-safe edits

Locate by scene № · character · location · keyword · dialogue · event · emotional beat · plot point (shows target + prev + next + related). Related-scene detection via the graph → apply-only / auto-update / review / ignore. Modes: replace · enhance · cinematic · stronger-emotion · stronger-action · same-voice · continuity-safe · dialogue-only · description-only · emotion-only · notes-only. Integrity → Before/After (diff + explanations → approve/reject/edit/save-as-alternate). History & canon: what/who/when/why + related affected + AI recs accepted; revert/restore/return-to-original; approved → canon.

Tool #2 — Scene Regenerate Engine

Safe single-scene regeneration (never the whole script). Smart-regenerate off full script + arcs + tone + timeline + canon. Three directions (emotional / action / cinematic — choose / combine / more). Hint mode (e.g. "Antara fights the Amalekite leader before earning his respect"). Impact analysis before save → what changed · scenes affected · continuity risks · fixes. Apply: replace · replace+related · review · alternate · keep · reject.

Story Bible + Synchronization

Per-script Character · World · Lore · Timeline · Relationship-map. On an approved change, a sync pass updates affected entries from canon (Amalekites become allies → World Bible + Timeline + relationship graph update; future analysis uses the new canon). Previewed before commit.

Conflict Detector

Scans canon + scenes for contradictions (S12 fears heights / S65 climbs casually). Emits ConflictFlag with explanation + related scenes + suggested fix, surfaced in Scene Workspace & Coverage.

Emotional Journey Tracker

Per-character emotion beats → a scene-by-scene arc (Fear → Hope → Anger → Triumph → Loss). Revisions that create discontinuity warn + show the graph + suggest corrections. Feeds the Emotion re-key before/after viz.

Tool #3 — Language Adaptation Studio

Adaptation, not translation. Preserves canon · approved revisions · voices · lore · world · continuity while producing EN/AR/FR/ES · festival · Hollywood-dev · subtitle · dubbing. 10 modes; comparison view (original · literal · creative · adaptation notes).

8 · Guardrails

  • Don't break the running app — additive composition; routes redirect, not deleted, until parity is proven.
  • Canon is append-only; sync and revisions write through approval, never silently.
  • Schema work is gated behind drift-reconcile + a backup DB; one migration per change.
  • Multi-tenancy stays separate (the release blocker) — don't couple v4 to it.
  • Respect intentional safety designs — no-faces look-board · no living-religion deities · representation-as-speaking-count.
  • Reuse audit before each build step — if a capability exists, relocate it; only build the connective tissue + the 7 new engines.
