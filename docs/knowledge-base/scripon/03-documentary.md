# 03 · Documentary

> Written in the edit, not scripted up front. Encoded in `knowledge/documentary.ts`.

A documentary is fundamentally different from scripted drama: you cannot write its dialogue in
advance because you do not yet have it. So the develop ladder **swaps** — there are no beat sheets
or dialogue scenes, and the narration script is written **last**, to a locked picture.

## The swapped stage chain (`DOC_LADDER`)

| Stage | What it is |
| --- | --- |
| `THESIS` | The argument the film makes, or the question it investigates. |
| `TREATMENT` | A *living* treatment — characters, access, visual approach, structure (revised throughout). |
| `RESEARCH_PLAN` | What footage, records and experts are needed. |
| `RIGHTS_PLAN` | Clearances: life-rights, music sync/master, archive, locations. |
| `INTERVIEW_OUTLINE` | Questions and sequences to capture. |
| `PAPER_EDIT` | The string-out — the film assembled from transcripts before/while cutting. |
| `NARRATION` | Written **last**, to the locked picture. |

## Two independent axes

Documentaries are described by two orthogonal choices; the engine reads both.

**Subgenre (the subject)** sets the default shape and the one blocking artifact that matters most:

| Subgenre | Default shape | Distinct artifact |
| --- | --- | --- |
| Nature / wildlife | 6–11 × 50 min by biome; "hero animal" sequences | season-locked shot wish-list + field schedule |
| Sports | event/season spine; outcome-known → dramatic irony | league/athlete access + archive |
| True-crime | 3–10 × 45–60 min; crime → investigation → trial → aftermath | legal/defamation pack (2-source rule) |
| Political / investigative | thesis-argument outline | fact-check / source-verification matrix |
| Biographical | life-arc or turning-point spine | life-rights / estate clearance |
| Music | scenes built around songs | **sync + master-use licensing plan** (budget-critical) |
| Observational / vérité | shoot-as-you-go; structure found in the edit | long shooting ratio + consent/release tracking |
| Essay | authored, voice-led argument | narration as the through-line |

**Nichols mode (the voice)** — Expository, Observational, Participatory, Reflexive, Performative,
Poetic. A true-crime film can be expository (voice-of-God) or participatory (host on camera); the
mode is chosen and held.

## Guardrails the engine surfaces

- **Outcome flag.** Known outcome (sports/historical) → structure for dramatic irony. Unknown
  (vérité) → structure is found in the edit, not pre-written.
- **Rights are tracked items, not prose.** Music sync/master, life-rights, archive and location
  clearances are surfaced explicitly because they gate budget and delivery — especially music docs.
