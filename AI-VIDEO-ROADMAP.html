2 · What you flagged is exactly right

The shot spec is too thin

Today a shot carries prompt, camera_movement, audio_fx, negativePrompt, seed. Missing the fields the engine actually leans on: location/set, lens, shot size, angle, zoom, lighting, wardrobe, facial expression, body language, color, continuity. Research below defines the full schema.

The ladder skips your knowledge

It jumps Premise → Shot List, ignoring the rich micro-drama ladder already in ScriptON: logline · synopsis · beats · outline · scenes · draft. You want a real pure script per episode + a fully-described generation spec. That's the standard AI-film split.

3 · 2026 best practice (researched)

  • Format: serialized vertical micro-drama — 60–80 episodes/series, 60–90s/episode, each episode several short scenes, each scene a separate ≤5s clip, stitched, ending on a cliffhanger.
  • The split (your point): "A screenplay tells the story; a shot plan tells how it's shown." Pipelines produce a pure script and a shot-by-shot prompt sheet — separate artifacts.
  • Shot Grammar (8 points): Subject & Action · Emotional Energy · Camera Optics · Motion · Lighting Physics · Style/Color · Audio · Continuity. Front-load subject + action (first ~25 words carry the most weight).
  • Character consistency = reference images, not text. "Identity lives in the reference, action lives in the prompt." 2–3 head-shots/character (straight-on · ¾ · profile), repeated stable identity phrase, ~70% identity / 30% motion.
  • Engine fit: Seedream 4.5 (image, same fal key) for the head-shots → Seedance 2.0 (video) for the scenes — one ByteDance stack, native audio.

4 · The enriched pipeline (what to build)

Leverage the micro-drama ladder ScriptON already has, then branch into the two artifacts you asked for, then render & stitch.

  1. Intake → series spec. Total duration or episode count × episode length (60–90s) → scenes/episode = round(len ÷ 5) ≈ 12–18.
  2. Logline → Synopsis → Story Engine. Existing stages — the premise, the repeatable conflict machine.
  3. Episode Map. N episodes, each a one-line logline + its cliffhanger.
  4. Per-episode Beat Sheet. Hook (0–15s) · Friction (15–60s) · Spike · Button/cliffhanger (freeze 55–58s).
  5. Per-episode Scene List. Beats broken into ≤5s scenes (one observable action each).
  6. Per-episode Draft = the PURE SCRIPT. Sluglines, action, dialogue — human-readable screenplay.
  7. Character Bible → approved head-shots. Seedream 4.5 generates 2–3 stills/character → you approve.
  8. Per-scene Shot Spec = the AI-GENERATION SCRIPT. The full Shot Grammar (section 5) per ≤5s scene.
  9. Render. Each scene → Seedance ≤5s clip, anchored to the character reference (+ last-frame chain).
  10. Stitch. Scenes → episode (ffmpeg) + subtitles + native audio, ending on the cliffhanger.

5 · The complete Shot Spec (per ≤5s scene)

This is the "AI-generation script" — every field the engine relies on. The prompt is assembled from these (front-loaded), and the structured fields stay editable.

Subject
character (stable identity phrase + reference head-shot), wardrobe/outfit, age/look
Expression
facial expression as emotion tokens ("micro-smile, eye glint, brows easing 0:00→0:04")
Body language
posture + the ONE primary physical action of the shot
Location / Set
environment, time of day, weather — the continuity lock
Camera
shot size (CU/MS/WS), angle (low/high/eye/dutch), lens (24/50/85/135mm), zoom, depth of field
Movement
camera move (push-in/pan/dolly) + pacing — never static-only
Lighting
key/fill/rim, direction, colour temp (3200K/5600K), quality (hard/diffused), volumetrics
Colour / Style
palette + film look (e.g. "amber-and-shadow, anamorphic, fine grain")
Audio
dialogue (lip-sync) · ambient · sfx · music cue
Continuity
character ref image(s), last-frame → next-scene chain, the lock sheet
Render
durationSec ≤5 · aspectRatio 9:16 · negativePrompt · seed · assembled prompt

Two artifacts per episode: ① Pure Script (story) and ② Shot Spec sheet (generation). The current VIDEO_PROMPT becomes artifact ②, enriched with the fields above.

6 · Episode beat engine

HOOK 0–15s the "explosion point" — world + stakes + image in 3s FRICTION 15–60s filmable conflict (physical/verbal, in frame) SPIKE ~50s the jolt / reversal BUTTON 55–58s freeze-frame cliffhanger — retention lives here

7 · Character consistency — the head-shot step

Seedream 4.5 (same FAL_KEY) generates 2–3 reference head-shots per character → you approve / regenerate → the approved stills anchor every scene's Seedance render. Keep angles similar, repeat the identity phrase, weight 70% identity / 30% motion. Alternatives to compare: Nano Banana Pro (headshot realism), Flux Kontext / Ideogram V3.

8 · Target architecture

intake (episodes × length) ─► logline → synopsis → story engine │ ▼ episode map (N × logline + cliffhanger) per episode ─► beat sheet → scene list (≤5s) → ① pure script (draft) │ character bible ─► Seedream head-shots ─► you approve │ per scene ─► ② shot spec (full Shot Grammar) ─► Seedance render (ref-anchored, ≤5s, 9:16, audio) │ per episode ─► stitch (ffmpeg) + subtitles ─► episode.mp4 ► series
